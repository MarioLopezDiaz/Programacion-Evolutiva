# 🧬 Programación Evolutiva

Este repositorio contiene las prácticas desarrolladas durante el curso de **Programación Evolutiva**, abarcando diferentes enfoques de algoritmos evolutivos aplicados a problemas de optimización y resolución automática.

## 📅 Prácticas Incluidas

### 🔹 Práctica 1
- Introducción a la búsqueda y optimización.
- Implementación de un **algoritmo genético simple**.

### 🔹 Práctica 2
- **Algoritmo evolutivo general** aplicado a **optimización combinatoria**.
- **Problema del Viajante de Comercio (TSP)**.

### 🔹 Práctica 3
- **Programación genética** y uso de **gramáticas evolutivas**.
- Resolución del **problema de la hormiga en el rastro de Santa Fe**.

---

Cada práctica incluye código, documentación y ejemplos para facilitar su comprensión y ejecución.
